# Recording Studio Application 🎙️

A small Java application created for Joysis TECH VOC INC. and the course Programming (Java) NC III. 🎓

What this project is
- A course project that demonstrates a basic Java application connecting to a MySQL database. 🎯
- Built as a learning exercise to show how Java programs can store and retrieve data. 💾

What it does
- Connects to a MySQL database to create tables, insert sample data, and run simple queries. 🗄️
- Includes example code and SQL scripts (in the repo) that illustrate common database operations. 🧩

What I used to build it
- Java (programming language) ☕
- MySQL (database) 🐬
- MySQL Workbench (DB tool) 🛠️
- Visual Studio Code (IDE) 🧑‍💻
- ChatGPT, Claude, and Copilot (AI collaborators) 🤖✨

How to run (very simple)
1. Install Java and MySQL on your machine. ✅
2. Create a database and run the provided SQL scripts (or import them with MySQL Workbench). 📥
3. Open the project in Visual Studio Code, set your database connection details, and run the main Java class. ▶️

If you'd like, I can add exact commands, a simple start script, or sample connection settings.
